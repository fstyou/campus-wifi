## 修改检查间隔

软件默认每 5 秒检测一次。下面的命令会将间隔改为 1234 秒；需要其他间隔时，只需替换其中的 `1234`：

```sh
(
    set -e
    /etc/init.d/campus-wifi stop
    python3 - 1234 <<'PY'
import json
from pathlib import Path
import sys

seconds = int(sys.argv[1])
if not 1 <= seconds <= 86400:
    raise SystemExit('间隔必须是 1 到 86400 秒之间的整数。')
path = Path('/etc/campus-wifi/config.json')
config = json.loads(path.read_text())
config['check_interval'] = seconds
path.write_text(json.dumps(config))
path.chmod(0o600)
print('检查间隔已修改。')
PY
    /etc/init.d/campus-wifi start
)
```

间隔越长，自动登录的反应越慢。按钮登录不需要等下一轮检查。

## 更换校园网账号

先停止程序并退出旧账号：

```sh
/etc/init.d/campus-wifi stop
python3 /usr/lib/campus-wifi/campus_wifi.py logout
```

没有报错后，再填写新账号并启动：

```sh
python3 /usr/lib/campus-wifi/campus_wifi.py configure
/etc/init.d/campus-wifi start
```

填写账号不会改变已设置的检查间隔。

## 修改认证服务器地址

先使用当前地址退出已保存的会话，再重新配置：

```sh
/etc/init.d/campus-wifi stop
python3 /usr/lib/campus-wifi/campus_wifi.py logout
python3 /usr/lib/campus-wifi/campus_wifi.py configure
/etc/init.d/campus-wifi start
```

程序会重新询问账号、密码、服务名称和认证服务器地址。地址只填写服务器基础地址，例如：

```text
http://10.255.100.2
```

不要填写 `/eportal/index.jsp`、认证页面后面的参数或账号信息。直接按回车会保留当前地址。

## 暂停运行

```sh
/etc/init.d/campus-wifi stop
```

需要登出时，在程序运行或停止时都可执行：

```sh
python3 /usr/lib/campus-wifi/campus_wifi.py logout
```

恢复运行：

```sh
/etc/init.d/campus-wifi start
```

取消开机自动运行：

```sh
/etc/init.d/campus-wifi disable
```

重新开启开机自动运行：

```sh
/etc/init.d/campus-wifi enable
```

## 升级

1. 在路由器终端执行 `/etc/init.d/campus-wifi stop`。
2. 在电脑上下载新版，按首页第 1 步上传新版文件。
3. 回到路由器终端，执行：

```sh
sh /tmp/campus-wifi/install.sh
/etc/init.d/campus-wifi start
```

已有账号、密码和检查间隔会保留，不需要再次填写。

## 查看 Wi-Fi 连接情况

执行：

```sh
python3 /usr/lib/campus-wifi/campus_wifi.py status
```

显示的记录数可能多于实际设备数，这是正常的，不影响判断是否还有设备连接。
