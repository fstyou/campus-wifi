# 详细说明

[返回首页](../README.md)

## 自动登录规则

程序定时读取路由器报告的 Wi-Fi 关联记录数。

默认每 5 秒检测一次。

| 上一次数量 | 本次数量 | 操作 |
| --- | --- | --- |
| 未记录 | 任意有效数量 | 只建立基准 |
| 任意数量 | 更大的数量 | 尝试登录 |
| 任意数量 | 相同或更小的数量 | 不执行认证操作 |
| 任意数量 | 无法确定 | 忽略本次结果 |

登录尝试失败后，相同数量不会重复尝试。以后数量再次增加时会重新尝试。短按实体按钮或执行 `login` 不受数量变化限制。

这里统计的是无线驱动返回的关联记录，不一定等于物理设备数量。同一设备使用不同随机 MAC、同时出现在多个无线接口或在频段之间切换时，记录数可能变化。

## Wi-Fi 检测

每轮检测都会枚举当前全部网络接口，不使用固定的无线接口名单。

程序只统计工作模式为 `Master` 的无线接入点，忽略：

- WAN 口 `eth0`；
- 有线接口和网桥；
- 工作模式为 `Client` 的无线中继上游；
- 未启用的接口。

程序优先通过 `ubus call hostapd.<接口> get_clients` 读取关联记录。厂商虚拟接入点没有 hostapd 对象时，改用 `iwinfo <接口> assoclist`。

如果接口列表在采样期间变化、没有发现可用接入点或关联查询失败，本轮状态会标记为“无法确定”，不会作为有效数量交给登录状态机。

## 校园网登录

所有认证请求固定经过 `eth0`。认证服务器基础地址读取配置文件中的 `portal_url`，旧配置缺少该字段时使用 `http://10.255.100.2`。

每次需要登录时，程序先访问 `http://123.123.123.123/`，从校园网重定向页面提取当前认证地址。认证地址中的参数会随网络会话变化，因此不会保存旧地址重复使用。

程序随后读取 ePortal 的页面信息和 RSA 公钥，按照认证网页的算法加密密码，再提交登录请求。只有服务器明确返回成功并提供 `userIndex` 时，才保存会话。会话同时记录认证服务器地址，避免切换地址后把旧会话发送给新服务器。

程序不会定期发送保活请求，也不会在关联数量不变时检查账号是否仍在线。如果账号被其他设备顶下线，可以按实体按钮或手动执行：

```sh
python3 /usr/lib/campus-wifi/campus_wifi.py login
```

## 后台命令

`login`、`logout` 和 `status` 在服务运行期间通过本机 Unix 数据报套接字交给后台进程串行处理。服务停止时，命令由当前进程直接处理。

控制套接字位于：

```text
/tmp/campus-wifi/control.sock
```

请求带有随机编号，调用终端只接受编号一致的响应。终端等待超时后不会自动重发，以免重复提交网络操作。

`status` 只读取当前 Wi-Fi 信息，不改变数量基准，也不推迟下一轮检测。

## 日志

后台服务只在状态变化、登录、手动退出或错误发生时输出日志，不为每一轮正常检测写日志。

同一个错误持续发生时：

1. 第一次立即记录；
2. 之后每 10 分钟最多记录一次；
3. 正常完成一轮检测后清除错误状态；
4. 不同错误分别立即记录。

## 实体按钮

`bind_reset.py enable` 会先核对原厂重置键脚本结构并保存备份，然后追加不足一秒的短按登录处理。备份位置为：

```text
/etc/campus-wifi/reset-button-backup.json
```

绑定工具不会覆盖无法识别的按键脚本。脚本在绑定后被其他程序修改时，解除绑定也会停止，避免覆盖其他改动。

重置键原有长按分支仍然存在。不要长按，以免重置网络或恢复出厂设置。

## 文件和权限

- 程序目录：`/usr/lib/campus-wifi`
- 配置目录：`/etc/campus-wifi`
- 临时目录：`/tmp/campus-wifi`
- 服务脚本：`/etc/init.d/campus-wifi`
- 账号配置：`/etc/campus-wifi/config.json`
- 已保存会话：`/etc/campus-wifi/session.json`

配置和会话文件权限为 `0600`，配置目录权限为 `0700`。校园网密码仍以明文保存在配置文件中，只允许 root 读取。

配置文件的主要字段：

- `username`：校园网账号；
- `password`：校园网密码；
- `service`：服务名称，通常为空；
- `portal_url`：认证服务器基础地址；
- `check_interval`：检测间隔，单位为秒。

`portal_url` 只接受 `http://` 或 `https://` 地址，不能包含路径、查询参数、片段或账号密码。程序只接受与该地址同源的 ePortal 重定向页面。

## 限制

- 仅在 GL.iNet MT3600BE 原厂 OpenWrt 21.02 和当前 ePortal 接口上验证过。
- 有线设备不会触发登录。
- 首次启动只建立数量基准。
- 关联变化短于检测间隔时可能不会被发现。
- 关闭全部无线接入点时状态会变为“无法确定”。
- 登录响应丢失时，可能需要通过校园网页面处理当前会话。
- 同一账号只允许一个设备在线时，主动登录可能使其他设备下线。

## 开发检查

运行时只使用 Python 标准库和路由器已有命令。提交前执行：

```sh
python3 -m unittest discover -s tests -v
python3 -m py_compile campus_wifi.py bind_reset.py
sh -n install.sh button-login.sh campus-wifi.init
```

如已安装 Ruff，再执行：

```sh
ruff check .
ruff format --check .
```
