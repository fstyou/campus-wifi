# 彻底卸载

[返回首页](../README.md)

--- 

在路由器 SSH 中执行下面整段。它会停止服务、取消开机启动、恢复原重置键脚本、登出已保存的校园网会话，然后删除程序、账号密码、会话、按键备份及临时文件。删除后无法用本程序恢复这些配置。

如果使用 nettask 或其他工具自行添加过本项目的登录命令，先在对应工具中移除；本项目不能自动修改其他工具的配置。

```sh
(
    set -e

    if [ -x /etc/init.d/campus-wifi ]; then
        /etc/init.d/campus-wifi stop
        /etc/init.d/campus-wifi disable
    fi

    if [ -f /usr/lib/campus-wifi/bind_reset.py ]; then
        python3 /usr/lib/campus-wifi/bind_reset.py disable
    fi

    # 原按键脚本仍引用本项目时，保留备份，不继续删除。
    if [ -f /etc/rc.button/reset ]; then
        if grep -q 'campus-wifi' /etc/rc.button/reset; then
            printf '卸载中止：重置键脚本仍引用本项目，请先恢复按键。\n' >&2
            exit 1
        fi
    fi

    if [ -f /usr/lib/campus-wifi/campus_wifi.py ] &&
       [ -f /etc/campus-wifi/config.json ]; then
        python3 /usr/lib/campus-wifi/campus_wifi.py logout
    fi

    rm -f /etc/init.d/campus-wifi /etc/init.d/campus-wifi.new
    rm -f /etc/rc.button/reset.campus-new
    rm -rf /usr/lib/campus-wifi /etc/campus-wifi /tmp/campus-wifi
    rm -f /tmp/campus-wifi.tar.gz /tmp/campus-wifi.zip
    rm -rf /tmp/eportal-check.*

    printf '卸载完成：程序、配置、会话、按键绑定和临时文件已清理。\n'
)
```

出现按键恢复或登出错误时，脚本会停止，不会继续删除备份和会话。请先处理错误再重新执行。如果以前台 `run` 方式运行，也要先在原终端用 Ctrl+C 停止，否则会话锁会阻止登出。

如果提示没有保存的会话，程序不会替你登出浏览器建立的会话；这类会话需要通过校园网页面处理。网络不可用时，删除本地文件也无法替代服务端登出。

Python、curl、LuCI 等共享依赖不会卸载，避免影响其他软件。系统日志不会整体清空；电脑或其他目录中自行保存的源码和压缩包可另行删除。
